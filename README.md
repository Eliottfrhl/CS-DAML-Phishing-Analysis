# CS DAML Phishing Analysis
CentraleSupélec Project made for the Data Analytics &amp; Machine Learning Course.

## How To
**Installation**
- Open a terminal in the project directory
- Create a Python virtual environment : `python -m venv .env`
- Activate the environment : `source .env/bin/activate` or `.\.env\Scripts\activate` if you are using Powershell
- Install the dependencies : `pip install -r requirements.txt`

**Running the notebook**
- Open the `PhishU_Master.ipynb` file
- Choose the previously created **.env** python environment as the kernel
- Run the cells in order : the notebook downloads the dataset and trains the models by itself

**Results**
All the output graphs will be located in the `outputs/` folder, and the last cell of the notebook provides a sum-up of the performances of the various models that were implemented.
